# Apocalipse Zumbi

Jogo de sobrevivência em ondas, feito com HTML, CSS e JavaScript puro.

Jogue agora: https://larandreluizinfo.github.io/apocalipse_zumbi/

## Como jogar

- Sobreviva a 10 rodadas de zumbis.
- Na rodada 10, o chefe desperta. Derrote-o para liberar o **Baú de Guerra**.
- Abra o baú com **E** para desbloquear todo o arsenal e escolher um veículo de fuga.
- Depois do chefe, você pode fugir e vencer ou continuar no modo infinito para usar as armas.

## Itens do Baú de Guerra

- Machado Gigante
- Lança Humana
- Arco e Flechas
- Espada
- Faca
- Metralhadora
- Carro blindado
- Moto
- Rota de fuga

## Controles

- **WASD** ou setas: mover
- **Mouse**: mirar
- **Clique**: atacar ou atirar
- **1 a 6**: trocar de arma (após abrir o baú)
- **E**: abrir ou acessar o baú
- **M**: ligar ou desligar o som
